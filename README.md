# macmade.dev

Kleine öffentliche technische Seite über die im Entwicklungsworkflow eingesetzten Werkzeuge und Infrastrukturkomponenten.

Der erste Stand beschreibt CodexJournal, Akasha und devMCP sowie zwei kleinere Praxisbeispiele. Er bleibt bewusst statisch, benötigt keine Datenbank und veröffentlicht keine Betriebsdetails.

## Lokal ausführen

```bash
npm install
npm run dev
```

## Prüfen

```bash
npm test
```
